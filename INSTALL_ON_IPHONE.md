# Как поставить ассистента на iPhone

Нужна HTTPS-ссылка на GitHub Pages. Локальный файл с компьютера iPhone не сможет установить как полноценное PWA-приложение.

После публикации откройте ссылку в Safari:

`https://USERNAME.github.io/REPOSITORY/`

Дальше: `Поделиться -> На экран "Домой" -> Добавить`.

Если приложение открылось с иконки на главном экране, установка прошла правильно.
