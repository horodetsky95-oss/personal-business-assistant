# Личный и бизнес-ассистент

PWA-версия ассистента для личных дел, матрицы Эйзенхауэра и бизнес-планирования.

## Публикация через GitHub Pages

1. Создайте новый публичный репозиторий на GitHub, например `personal-business-assistant`.
2. Загрузите все файлы из этой папки в корень репозитория.
3. Откройте `Settings -> Pages`.
4. В блоке `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/(root)`, затем нажмите `Save`.
6. Через несколько минут сайт появится по адресу вида:
   `https://USERNAME.github.io/personal-business-assistant/`

## Установка на iPhone

1. Откройте опубликованную ссылку в Safari на iPhone.
2. Нажмите кнопку `Поделиться`.
3. Выберите `На экран "Домой"`.
4. Нажмите `Добавить`.

После этого ассистент будет открываться как отдельное приложение. Без облака данные хранятся локально в браузере на устройстве.

## Синхронизация между iPhone и веб-версией

В приложении добавлена синхронизация через Supabase. Инструкция находится в файле `SUPABASE_SETUP.md`.

После настройки:

1. Нажмите кнопку `Облако`.
2. Введите email.
3. Подтвердите вход через письмо.
4. Войдите с тем же email на другом устройстве.

Задачи, бизнес-пункты и заметки будут синхронизироваться между устройствами.

## Голосовые заметки

В разделе `Заметки` добавлена кнопка `Голосовая заметка`. Если браузер поддерживает распознавание речи, текст попадет в заметку автоматически. На iPhone также можно нажать поле заметки и использовать микрофон на клавиатуре.

## Напоминания

У каждой задачи есть кнопка календаря. Она создает файл `.ics`, который можно открыть на iPhone и добавить в Apple Calendar. Событие создается с напоминанием за 15 минут.
