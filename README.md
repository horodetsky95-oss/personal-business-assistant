# Личный и бизнес-ассистент

PWA-версия ассистента для личных дел, матрицы Эйзенхауэра и бизнес-планирования.

## Публикация через GitHub Pages

1. Создайте новый публичный репозиторий на GitHub, например `personal-business-assistant`.
2. Загрузите все файлы из этой папки в корень репозитория.
3. Откройте `Settings -> Pages`.
4. В блоке `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/(root)`, затем нажмите `Save`.
6. Через несколько минут сайт появится по адресу вида:
   `https://USERNAME.github.io/personal-business-assistant/`

## Установка на iPhone

1. Откройте опубликованную ссылку в Safari на iPhone.
2. Нажмите кнопку `Поделиться`.
3. Выберите `На экран "Домой"`.
4. Нажмите `Добавить`.

После этого ассистент будет открываться как отдельное приложение. Данные хранятся локально в браузере на устройстве.
